# Koreatrip1 — Verified Korea Itinerary (Oct 31–Nov 9, 2026)

Professional, mobile-friendly travel itinerary site for two adults:
Seoul (Myeongdong) → Busan (Haeundae). Every hour, fare, and closing day was
verified line-by-line against official sources on 2026-10-21. Anything that
could not be confirmed officially is left blank and flagged — never guessed.

**Live site (GitHub Pages):** https://buffedlizard55-lab.github.io/Koreatrip1/

## Pages (`docs/`)
- `index.html` — dashboard (trip at a glance, hotels, day cards, checklist)
- `itinerary.html` — corrected day-by-day plan (Days 2–3 swapped: palace closed Tuesdays)
- `places.html` — sights/markets/malls/hotels table with official source per row
- `food.html` — restaurants/cafés/shops (verified vs. unverified w/ Naver Map links)
- `transport.html` — ICN transfers, Seoul legs, KTX to Busan
- `verification.html` — line-by-line audit of the original notes (V-01…V-35)
- `flagged.html` — Flagged for Review (F-01…F-19)
