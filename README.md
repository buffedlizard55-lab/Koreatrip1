# Koreatrip1 — Verified Korea Itinerary (Oct 31–Nov 9, 2026)

Professional, mobile-friendly travel itinerary for two adults:
Seoul (Myeongdong) → Busan (Haeundae). Every hour, fare, and closing day was
verified line-by-line against official sources (2026-10-21). Anything that
could not be confirmed officially is left blank and flagged — never guessed.

**Live site (GitHub Pages):** https://buffedlizard55-lab.github.io/Koreatrip1/

## Site map
Primary dashboard (repo root, data-driven from `data/trip.json`):
`index.html` · `itinerary.html` · `entries.html` · `transit.html` ·
`hours.html` · `flagged.html` · `sources.html` (+ `legacy/` early drafts).

Companion detailed plan (`docs/`, linked from the dashboard):
- `docs/index.html` — summary + before-you-go checklist
- `docs/itinerary.html` — corrected day-by-day (Days 2–3 swapped: palace closed Tuesdays)
- `docs/places.html` / `docs/food.html` / `docs/transport.html` — sourced tables
- `docs/verification.html` — claim-by-claim audit (V-01…V-35)
- `docs/flagged.html` — Flagged for Review (F-01…F-19)
