# Korea Trip itinerary dashboard

A mobile-friendly, static GitHub Pages site for the supplied two-adult Seoul → Busan itinerary.

## Pages
- `index.html` — trip overview and day cards
- `itinerary.html` — day-by-day plan; every itinerary row includes an official primary-source/operator link
- `transport.html` — official public-transit references and planning checklist
- `review.html` — explicitly flagged date conflicts, unverified venue details and other irregularities

## Publish with GitHub Pages
In the repository settings, open **Pages**, set the source to **Deploy from a branch**, select `main` and `/ (root)`, then save. The site has no build step or dependency. The current session branch is not changed by this documentation; publish after integration into `main`.

## Verification policy
A source link does not imply a trip-specific fact is verified. Values that lacked an exact official confirmation (including dates, bookings, branch hours, route durations/fares and menu prices) are left unconfirmed and surfaced on the Flagged for review page. Recheck live source pages close to travel.
